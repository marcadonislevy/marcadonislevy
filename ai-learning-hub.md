# Free AI Learning Hub

A practical pathway for learning AI, building agents, and moving from beginner concepts to working agentic systems.

## 1. Start here: AI foundations

### Microsoft Learn — AI Learning Hub
Free Microsoft learning for AI fundamentals, generative AI, Microsoft Foundry, Copilot and agents.

https://learn.microsoft.com/en-us/ai/

Recommended:
- AI concepts for developers and technology professionals
- Introduction to generative AI and agents
- Introduction to building AI agents
- Agent in a Day

### OpenAI Academy
Free practical AI learning from OpenAI, covering everyday AI use, workflows, builders and adoption.

https://academy.openai.com/pages/courses

Recommended:
- AI Foundations
- Build with AI
- Agentic workflows and practical ChatGPT use

## 2. Learn to build AI agents

### OpenAI — Building Agents
A beginner-friendly official learning track covering agent concepts, tools, orchestration, guardrails and the Agents SDK.

https://developers.openai.com/tracks/building-agents

### OpenAI Agents SDK
Official SDK documentation for building code-first agents in Python or TypeScript.

https://developers.openai.com/api/docs/guides/agents/sdk

### Microsoft Agent Framework
Step-by-step Microsoft tutorial covering your first agent, tools, memory, workflows, multi-step execution and hosting.

https://learn.microsoft.com/en-us/agent-framework/get-started/

### Hugging Face AI Agents Course
Free course from beginner to advanced, covering agent fundamentals, tools, smolagents, LangGraph, LlamaIndex and deployment.

https://huggingface.co/learn/agents-course/en/unit0/introduction

### LangChain Academy
Free courses for building, testing, deploying and monitoring agents with LangChain, LangGraph, Deep Agents and LangSmith.

https://academy.langchain.com/

## 3. NVIDIA AI and agent training

### NVIDIA Open Source Courses
Free, openly licensed NVIDIA course materials covering deep learning, generative AI, agentic AI and secure agents.

https://www.nvidia.com/en-gb/training/open-source/

Useful areas:
- Fundamentals of Deep Learning
- Agentic and generative AI
- Securing agents with NemoClaw and OpenShell

## 4. Build agents visually or with low code

### n8n Academy
Free structured courses with certificates and badges. Learn workflows, APIs, automation and AI agents.

https://n8n.io/education/

### Dify
Open-source platform for building agents, RAG workflows, knowledge pipelines and deployable AI apps.

https://dify.ai/

### Microsoft Copilot / Foundry agent learning
Microsoft Learn includes hands-on pathways for Copilot agents and Microsoft Foundry.

https://learn.microsoft.com/en-us/training/paths/ai-success-build-ai-agents/

## 5. Google agent learning

### Google GEAR — Gemini Agent Ready
Google's no-cost agent-skilling hub for building, deploying and scaling AI agents.

https://developers.google.com/program/gear

## Suggested learning order

1. Microsoft Learn AI fundamentals
2. OpenAI Academy AI Foundations
3. Hugging Face AI Agents Course
4. OpenAI Building Agents track
5. LangChain Academy
6. Microsoft Agent Framework
7. NVIDIA open-source AI courses
8. Build a real workflow with n8n or Dify
9. Move into production agent design, evaluation, security and governance

## What you should be able to do after this pathway

- Understand generative AI and large language models
- Write effective prompts and instructions
- Build single and multi-agent systems
- Connect agents to tools, APIs and data
- Use MCP and agent frameworks
- Build workflows visually or in code
- Add memory, RAG, guardrails and human approval
- Test, evaluate and monitor agents
- Deploy agents into websites, applications and business workflows
- Understand responsible AI, safety and governance
